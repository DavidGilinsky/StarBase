# StarBase

A standalone astronomy project, related to the NightWatcher collection of tools
but deliberately not part of its toolset: its own repository, its own lifecycle,
and no dependency on the shared NightWatcher database (`nwdb`) or the extension
registry.

## Status

Bootstrapped 2026-07-23. Purpose, language, and architecture are still to be
defined.
